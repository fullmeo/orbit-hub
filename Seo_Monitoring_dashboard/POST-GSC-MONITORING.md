## 🚨 TROUBLESHOOTING: WHAT TO DO IF...

### "Pages Not Getting Indexed"

**If after 7 days, pages still "Discovered" not "Valid":**

```
1. Check index.html source code
   - Right-click site → View Page Source
   - Search: "noindex"
   - If found, remove it

2. Check robots.txt
   - Visit: orbit-allysonglado.netlify.app/robots.txt
   - Should say "Allow: /"
   - If says "Disallow:", fix it

3. Check for redirects
   - Each URL should load properly
   - No redirect loops

4. Resubmit in GSC
   - URL Inspection → Request Indexing again
   - For each non-indexed page

5. Check for errors
   - GSC → Coverage → Errors
   - Fix any listed issues
   - Re-request indexing
```

### "Coverage Shows Excluded Pages"

**If some pages show "Excluded":**

```
1. Click "Excluded" in Coverage
2. Hover over reason
3. Common reasons:
   - "Duplicate": Fix canonical URLs
   - "Blocked by robots.txt": Update robots.txt
   - "Alternate page with proper canonical": Expected for duplicates
   - "Noindex": Remove noindex tag

4. Fix the issue
5. Request re-indexing in URL Inspection
```

### "No Clicks or Impressions"

**If Performance tab shows 0 data after 3 days:**

```
1. Wait longer (data takes 2-3 days to appear)
2. Check if pages are actually indexed
   - GSC → Coverage → "Valid" tab
   - Should show pages

3. Pages may be indexed but not ranking
   - Try Google search: "Allyson Glado"
   - If not on page 1-10, ranking is low

4. Improve content
   - Add more blog posts
   - Improve meta descriptions
   - Add more keywords naturally

5. Build backlinks
   - Guest posts about reggae music
   - Social media shares
   - Music blog mentions
```

### "Crawl Errors Appearing"

**If GSC shows crawl errors:**

```
1. Click on error in Coverage
2. Google will show which pages have issues
3. Common issues:
   - 404 Not Found: Fix broken links
   - 500 Server Error: Check Netlify status
   - Timeout: Page too slow, optimize

4. Fix the issue
5. Use "Validate fix" in GSC
6. Re-request indexing
```
