🎵 Fan Chat Demo

Test UX/UI without API Keys

✅ DEMO MODE 🚫 NO API REQUIRED 💻 FULLY INTERACTIVE

How to Test

  • 1. Look for the 💬 chat button in the bottom-right corner
  • 2. Click to open the chat window
  • 3. Type a message and hit Enter or click Send
  • 4. Wait 1.5 seconds for a mock response
  • 5. Messages persist in localStorage (refresh page to see)
💡 Tip: This demo uses keyword-based responses. Try keywords like: hello, album, spotify, paris, collaborations, concert, etc.

Features Tested

  • ✅ Open/Close: Click button to toggle chat
  • ✅ Send Message: Type and press Enter or click Send
  • ✅ Typing Indicator: See "..." while waiting
  • ✅ Auto-scroll: Chat follows new messages
  • ✅ Persistence: Messages saved in localStorage
  • ✅ XSS Safety: No HTML injection possible
  • ✅ Mobile Responsive: Works on all screen sizes
  • ✅ Dark Mode: Default reggae-pop theme
  • ✅ Accessibility: WCAG AA compliant
  • ✅ Input Validation: Max 1000 chars
