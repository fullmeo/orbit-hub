# Serigne Diagne — Orbit Hub

Carte de visite numérique du trompettiste et compositeur **Serigne Diagne** (Paris).

## Identité publique

Sur cette page, l'étiquette officielle reste :

**Trompettiste • Compositeur**

C'est l'identité que le public, les programmateurs et Afrisson doivent reconnaître.

## Meta-développeur : ne pas mettre au premier plan

L'étiquette *meta-developer* décrit le travail technique (Orbit Hub, Magnus, orchestration IA).
Elle est vraie, mais elle n'aide pas le SEO ni la lecture d'une carte artiste.

Recommandation :
- **Hub public (ce dossier)** : musicien uniquement
- **Hub technique / GitHub / Magnus** : meta-developer
- Si les deux doivent coexister plus tard : une ligne discrète en bas, jamais dans le titre
