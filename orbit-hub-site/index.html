Orbit Hub

Infrastructure de visibilité pour artistes indépendants

Une présence en ligne éparpillée sur dix plateformes ne se retrouve pas. Orbit Hub place un hub unique au centre : les plateformes gravitent autour, le public passe par une seule porte.

Voir le projet sur GitHub

Le principe

Un hub central

Une page par artiste, rapide, optimisée pour Google et pour le mobile.

Les plateformes en orbite

Streaming, réseaux sociaux, newsletter : tout est relié depuis le hub.

Mesure et soutien

Suivi GA4, pourboires et chat des fans pour prolonger la relation.
